# 角色动画与声音生成：方案

日期：2026-11-12。状态：方案与页面原型；后台未实现。

## 要解决的问题

现在做一个自定义角色，要自己准备三段动画（空闲中、忙碌中、需要确认）和对应的声音，门槛很高，抠图也常常不干净。目标是：用户上传一张角色图和一段声音，云空间帮他生成三段能直接用在桌宠和硬件屏上的动画，以及用他上传的声音说出的三句话；生成结果作为备选，用户挑满意的替换主动画。

## 用户流程

入口是每个角色上的"重新生成"按钮（角色卡片右上角、角色编辑页标题行）。生成页分四步，每步都可以单独重做：

1. **角色形象**：上传一张角色图（默认取当前"忙碌中"动画的第一帧）。
2. **动作描述**：AI 看图后为三种状态各写一段动作描述，用户可以直接改字，也可以让 AI 重写某一段。
3. **生成动画**：每种状态一次出 3 个备选。每个备选依次经过生成、去背景、首尾衔接、压缩成 GIF；完成后附 AI 质检结论（形象是否一致、循环是否自然、有没有残影）。用户点"设为主动画"替换，旧的主动画保留在备选里，可以换回。
4. **声音**：上传 10–30 秒的人声，勾选授权声明后克隆音色；三种状态各填一句台词、选一种情绪和强度，每次生成 2 个版本，选中的设为该状态的声音。

生成是异步任务：关掉页面不影响，回来能看到进度和结果。替换主动画、设为声音都走现有的云同步，桌宠一分钟内用上。

## 后台流程

```
上传图片 ─► 角色理解（Claude）─► 三段动作描述 ─(用户确认/修改)─►
  每种状态 × 3 个备选：
    图生视频（首尾帧同一张图）─► 逐帧抠图 ─► 时序清理 ─► 首尾衔接/补帧
    ─► 对齐与裁切 ─► GIF 量化（透明边处理）─► AI 质检打分 ─► 备选列表

上传声音 ─► 降噪/切静音 ─► 音色克隆 ─► 声音 ID
台词 + 情绪 + 强度 ─► 带情绪的语音合成（2 个版本）─► 响度归一 ─► 备选列表
```

### 1. 角色理解与动作描述（Claude）

用 **Claude Opus 5.5**（`claude-opus-5-5`）的图片理解：一次请求读图，按固定结构返回角色外观要点（发色、服装、配饰、画风、视角）和三段动作描述。结构化输出（`output_config.format`）保证拿到的是可直接填进页面的字段；动作描述里写明桌宠场景的硬约束：镜头固定、角色居中、首尾姿势相同以便循环、纯色背景便于抠图、时长 3–4 秒、动作幅度不要出画。"让 AI 重写这一段"是同一个请求只要一个字段。需要处理拒答（`stop_reason: "refusal"`）：上传的图被安全分类器拦下时，页面提示换一张图。

### 2. 图生视频

候选（按国内可用性和对本场景的匹配度排序）：

| 模型 | 用法 | 说明 |
| --- | --- | --- |
| Seedance 2.x 图生视频（火山引擎） | 首帧 + 尾帧都给原图 | 首选。动作自然、国内可直接调用，首尾帧同图可以生成闭合循环；2.5 版本支持首尾帧 |
| 可灵 Kling v3（快手） | 首尾帧 | 备选，人物一致性好 |
| Vidu Q4 | 首帧锁定 | 备选，原图作为第一帧 |
| Masko 角色动画 API | 循环 / 过渡，原生透明输出 | 唯一原生输出透明背景、专做角色循环的服务，但在海外、按秒计费（约 $0.25/秒），适合作为高质量档位或做对照 |

每次请求只生成一种状态的一个备选，3 个备选并发；视频分辨率取 720p 即可（最终 GIF 只有 480px）。生成失败或质检不过的备选自动重试一次。

### 3. 精加工（自建 GPU 服务）

这一步决定能不能直接用在桌宠上，也是之前手工抠图出问题的地方，按顺序：

1. **逐帧抠图**：BiRefNet / RMBG-2.0 输出带半透明边缘的 alpha。纯色背景下也可以先用色键粗抠再用模型修边。
2. **时序清理**：单帧抠图会帧间抖动（发丝缝隙里的白块有的帧有、有的帧没有，就是这个问题）。对 alpha 做相邻帧投票/平滑，沿用 `device/tools/gif-matte` 里已经验证过的"邻帧多数抠掉就跟着抠"的思路。
3. **首尾衔接**：在序列里找与第一帧最接近的一帧作为循环点，裁掉多余部分；接缝处用 RIFE 补 2–4 帧过渡。
4. **对齐与裁切**：以角色脚底/桌面为锚点逐帧对齐，消掉视频模型带来的轻微镜头漂移；统一裁成正方形 480×480，留出边距。
5. **GIF 量化**：先预乘 alpha 再量化调色板，透明像素颜色清零，避免缩小时出现绿边/白边；帧率 15–20，控制单个文件在 2–6 MB（硬件屏内存有限）。

### 4. AI 质检与排序

精加工后的 GIF 抽 6 帧拼成一张图，交给 Claude Opus 5.5 和参考图对比，返回结构化结论：形象一致（发型、服装、配色）、动作是否符合描述、循环接缝、残影/多余肢体、抠图残留。备选按得分排序，页面上用一句话写出问题（"第 3 秒手部有残影"），不只给分数。

### 5. 声音克隆与合成

| 方案 | 说明 |
| --- | --- |
| IndexTTS-2.5（bilibili，自建） | 首选。单段参考音频克隆，情绪和音色可以分开控制，支持控制时长；中文表现好。许可证是自定义许可，商用前要确认条款 |
| Fun-CosyVoice 3.0（阿里，自建） | 备选。Apache 2.0，支持 18 种以上方言、流式输出、首包延迟低；情绪控制不如 IndexTTS 细 |
| 商用声音复刻 API（如火山引擎、MiniMax） | 不想自建 GPU 时的选择，按调用计费 |

流程：参考音频先降噪（DeepFilterNet 一类）、切掉静音，长度不足 10 秒时提示重录；克隆得到声音 ID 存在用户空间里，之后每句话只需要传声音 ID、台词、情绪和强度。台词可以让 Claude 根据角色设定和状态写几条候选（"需要确认"要短、要能一听就明白）。合成后统一响度（-16 LUFS 左右），截成 3 秒以内，和现有提示音的长度相近。

### 6. 任务与存储

- 新增任务接口：`POST /api/gen/jobs`（类型：describe / animate / voice-clone / speak）、`GET /api/gen/jobs/:id`、`GET /api/gen/jobs?character=...`；任务状态 queued / running(阶段) / done / failed。
- 结果写进用户自己的空间，路径放在 `animations/gen/` 下，计入 500 MiB 配额；"设为主动画"只是改角色设置里的文件名，复用现有的同步和版本号机制。
- 生成需要额度：每次动画备选、每次克隆、每句语音分别计数，按账号限流；GPU 任务排队，页面上显示前面还有几个。

### 7. 授权与安全

- 克隆声音前必须勾选"这是我自己的声音，或我已获得声音所有者的授权"，记录勾选时间；不提供"克隆名人声音"之类的预设。
- 上传的图片和声音只存在用户自己的空间，不用于训练，删除角色时一并删除。
- 合成语音在文件元数据里标注 AI 生成。

## 成本估算（每个角色完整生成一次）

- 动画：3 种状态 × 3 个备选 × 4 秒。以 Seedance/可灵按条计费估算，约 9 条视频；若用 Masko 约 9 × $1 左右。精加工在自建 GPU 上每条几十秒。
- Claude：读图写描述 1 次 + 质检 9 次，每次一张拼图，量很小。
- 声音：克隆 1 次 + 3 句 × 2 个版本。

价格和模型版本变化很快，接入前要按当时的价目表重新核算。

## 分期

1. 第一期：动作描述 + 图生视频 + 精加工 + 备选替换（不含质检、不含声音）。
2. 第二期：AI 质检排序、单段重做、失败自动重试。
3. 第三期：声音克隆与带情绪合成、AI 写台词。

## 页面原型

已在云空间实现可点击的原型：角色卡片和角色编辑页上的"重新生成"按钮进入生成页，四个步骤都能操作，进度和结果用演示数据模拟，不会修改角色、不会上传任何文件。
