# 副屏布局设计

此布局已接入 Windows 专属副屏模式。以 1280 × 720 专属画面为横屏基准，保留角色、时钟、日期、任务和提醒的内部布局。副屏窗口覆盖整块屏，桌宠、系统监控和背景按各自的区域绘制。

## 按屏幕尺寸排版

- 标准横屏沿用现有布局。更宽的横屏以 `round(屏高 × 16 / 9)` 作为桌宠区宽度，桌宠区与屏幕等高。角色、时钟和任务一起移动，内部构图保持一致。较窄横屏优先保留现有左右布局。如果时钟或当前任务放不下，先适当缩小角色区，再切到上下排列。宽高比低于 4:3 时直接采用上下排列，避免方屏上的角色占满信息区。
- 自动布局在能显示监控时把桌宠放左边，监控放右边。监控关闭或空间不足时，自动布局把桌宠居中。手动选靠左或靠右时始终按选择摆放，另一侧显示监控或延续舞台背景。角色和任务在桌宠区内的顺序保持一致。
- 竖屏沿用纵向构图。屏高超过 `round(屏宽 × 16 / 9)` 时，桌宠区以 9:16 显示，若监控开启且底部容得下精简指标，桌宠靠上、监控在下，否则桌宠居中。横屏的靠左或靠右设置在旋回横屏后恢复使用。
- 监控初版默认关闭，以设备为单位保存开关和摆放选择，并在分辨率、方向或设备改变时重新计算布局。菜单放在 **设备 → 副屏设备 → 屏幕布局**，提供 **自动、桌宠靠左、桌宠靠右**。**显示系统监控** 单独开关。

## 系统监控

- 精简版显示大字 CPU、内存使用率。完整版本可加入 GPU、显存和网络，其中 GPU 数据由现有采样能力决定。不可用的可选指标收起，等待采样时显示 `—`。
- 横屏完整监控初步需要屏高至少 540 px，且侧栏宽度按 720 px 屏高折算至少 520 px。精简监控需要屏高至少 320 px，侧栏实际宽度至少 180 px，且折算宽度至少 300 px。更小的区域延续背景。竖屏底部仅显示精简版，初版要求宽度至少 360 px，且余高至少为 `max(140 px, 屏宽 × 220 / 720)`。
- 门槛用于第一轮样机。渲染时用字体实际量测中英文标签和最长读数，放不下就降级或收起，保持清楚的字号。完整监控的内容宽度可封顶，超长屏的其余空间延续背景。采样复用 `SysMonitor`，按普通桌宠、专属副屏及现有外部读取需求决定是否启用。

## 接入与验收

Windows 专属模式从旋转后的实际输出尺寸计算桌宠和监控区域。桌宠区沿用 `TaskPanel::screenLayout` 与 `TaskPanel::renderScreen`，角色、舞台光、文字和任务统一使用局部坐标，再合成到整屏。全屏背景、亮度和鼠标拦截使用整块物理显示器的范围，监控区和留空区都纳入拦截。

USB 直连后端目前按固定的 720 × 1280 输出帧编码。首版以 Windows 专属模式为实现范围。直连支持识别各机型输出尺寸和方向后，再把同一布局计算接到全屏帧合成。无线设备沿用自己的布局入口。

已用表中尺寸生成预览，覆盖标准横屏、超宽屏左右布局、短屏、方屏和长竖屏。实机回归时检查旋转和热插拔后是否采用新尺寸、开关监控后是否保持手动指定的摆放位置，以及鼠标从相邻屏幕移向副屏的监控区或留空区时是否仍被挡住。
