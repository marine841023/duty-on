# DutyOn v2.0.2 — 跨显示器缩放修复版

## 修复

- **拖到低分辨率屏不再缩得过小**：把宠物从高 DPI 主屏拖到 1080p@100% 副屏时，
  角色和字体此前按 0.85 系数整体缩小，比 1.x 在同屏的尺寸还小、观感骤缩。
  分辨率归一化下限提升到 1.0——≤1440p 的屏幕与 1.x 尺寸完全一致，
  归一化只用于高分屏放大。
- **小字号点阵光栅扩展到所有屏幕**：<13px 的 CJK 文本在任何屏幕都保留
  MonoHinting 点阵渲染（实心 1px 笔画），避免灰度 AA 把笔画涂抹成灰雾。

## 说明

- 本问题为 2.0 原生渲染独有（1.x 为 WebView，浏览器自带 DPI 处理），1.x 不受影响。
- 升级直接覆盖安装，配置与形象保留。
