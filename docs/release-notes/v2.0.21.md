# Duty On v2.0.21 · 专属副屏与独立音量

把桌宠安顿到副屏，把提醒送到你选的扬声器。这个版本更新了设备菜单，加入两种副屏输出模式，以及独立的 Windows 提示音设置。

## 副屏：先选硬件模式，再选 Duty On 输出

| | 直连模式（USB） | Windows 副屏模式 |
| --- | --- | --- |
| **适合** | 兼容的 TURZX 屏直接显示桌宠，不加入 Windows 桌面。 | 把兼容的 TURZX 屏作为 Windows 扩展显示器，并全屏显示桌宠。 |
| **图灵官方工具** | 选择「普通模式」。 | 选择「桌面模式」，安装显示驱动，并在 Windows 启用扩展显示。 |
| **Duty On** | 「设备 → 副屏设备 → 副屏模式」选择「直连模式（USB）」。 | 在同一菜单选择「Windows 副屏模式」，再开启「TURZX 桌宠专属屏」。 |

Duty On 的菜单只切换软件输出，硬件模式和驱动需单独设置。直连当前仅支持已适配的设备，使用固定的 720 × 1280 帧；自适应布局和鼠标拦截适用于 Windows 专属副屏。

- **专属屏布局**：选自动、桌宠靠左或靠右；系统监控可单独开启。16:9 保持完整桌宠画面。超宽屏有空间时可并排显示监控，例如 2560 × 720 可一半放桌宠、一半放监控。方屏或窄屏会调整构图；监控会按空间精简或收起。
- **鼠标不乱跑**：「禁止鼠标进入」覆盖整块专属副屏，包括监控区和留白；按住 **Ctrl + Alt** 可临时进入。
- **配对入口**：Wi-Fi 配对归入「设备 → 无线设备」；设备共用设置仍在「设备」下。详见 [副屏布局指南](../secondary-display-layout.md) 和 [TURZX 接入说明](../turzx-display.md)。

## 声音与任务提醒

- PC 桌宠和 Windows 副屏共用「声音管理 → 声音输出设备 / 音量」。提示音和试听可指定 Windows 输出，并独立调节音量（0%～100%，每 10% 一档）。设置自动保存，不影响系统主音量或其他应用。
- Wi-Fi 配对设备在线时，PC 提示音临时走 Windows 当前的默认输出；离线后恢复 Duty On 保存的输出。音量设置继续有效。
- 改进 TRAE 的确认状态处理，减少用户已经处理审批后仍留在「需要确认」的情况。

Windows 10 / 11 x64 可在 [官网](https://dutyon.megrezsoft.com/#download) 下载。已安装的用户可通过「云端账户 → 检查更新」升级。
