# DutyOn v2.0.16 — 正式云服务上线

## 变更

- 云服务上线 https://dutyon.megrezsoft.com，提供安装器、安装器 ZIP、OTA、账号和用户私有云空间。
- 官方客户端默认使用此 HTTPS 主地址；仍可配置自建服务。
- 云服务运行镜像改为 scratch，仅包含静态 Go 程序和数据目录，以非 root 身份运行；增加独立健康检查模式。
- 增加已有 Nginx 主机的 Compose 覆盖配置、HTTPS 代理示例和本机交叉编译部署方式，更新备份恢复文档。
- 中英文首页改为正式云端 2.0.16 下载链接。GitHub/Gitee 历史 Releases 保留原版本。

## 验证

Go 测试、vet、Linux amd64 交叉编译与 Windows Release 构建通过。云服务已在 Linux + Docker 上实际部署，HTTPS 证书校验及容器健康检查通过。

实际 Windows C++ 云客户端通过正式 HTTPS 服务完成注册、中文文件上传、配置过滤、同名文件冲突保护、恢复、再次同步、更新检查、登录和注销失效验证。三类发布包均从公网下载，长度、SHA-256 及完整文件内容与本地构建一致。

独立客户端以 2.0.15 版本验证默认云地址，成功发现 2.0.16、下载 OTA、校验 SHA-256 并解压到隔离的暂存目录；未执行覆盖安装。

安装包目录：`tools/dist/`，包含 `DutyOn_2.0.16_x64-setup.exe`、`DutyOn-v2.0.16.zip`、`DutyOn-update-v2.0.16.zip`。

图片生成角色、声音克隆仍未接入。服务仍为单实例文件存储，限制及部署说明见[云服务文档](../../server/README.md)。
