# DutyOn v2.0.3 — 后台运行修复版

## 修复

- **启动后任务栏不再出现图标**：宠物完全后台运行，仅保留系统托盘图标。
  此前 GLFW 创建窗口默认立即可见，窗口先以普通应用身份被任务栏收录，
  之后才应用 `WS_EX_TOOLWINDOW` 样式，任务栏按钮就此留下。
  现在窗口改为**隐藏创建**（`GLFW_VISIBLE=FALSE`），样式与位置就绪后才
  `glfwShowWindow` 显示——此时已带工具窗口样式，任务栏全程不收录。

## 说明

- 退出/设置入口不变：系统托盘图标右键 + 宠物右键菜单。
- 升级直接覆盖安装，配置与形象保留。
