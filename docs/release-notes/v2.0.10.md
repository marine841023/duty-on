# DutyOn v2.0.10 — 配网全面加固 + 配对弹窗重做

## 新增 / 改进（设备端配网，本版重点）

- **热点可靠性自愈闭环**：Unisoc WiFi 芯片存在 beacon 槽位泄漏——hostapd
  同一 boot 周期内第二次启动必报 ENOMEM，软件层无解。设备现每 5 秒监测
  hostapd 存活，死亡即幂等重启；连续 3 次失败自动整机重启，冷启动第一任
  hostapd 必活，热点不再"搜不到 / 一连就断"。
- **配网页自动弹出**：对系统联网探测请求（Android `generate_204`、Windows
  NCSI、iOS `hotspot-detect` 等）返回 302 重定向到配网页，手机连上热点后
  无需手动输地址，系统自动弹出配网窗（ESP 类配网标准做法）。
- **配网页两步式交互**：先在扫描列表点选 Wi-Fi（设备扫周边网络供点选，免
  手输 SSID），再输密码连接；未扫到 / 隐藏网络走手动输入，误触更少。
- **ARP 保活**：配网态每 5 秒广播 ping 刷新手机 ARP 表，消除 DHCP 后短暂
  "页面打不开"的窗口。
- **热点信道自适应**：起热点前扫描周边，自动选 1/6/11 中最空闲信道；
  hostapd 增加国家码 CN 等合规配置，避免低功率发射搜不到热点。
- **接口抢占根除**：清理 netplan / wpa_supplicant / dhcpcd 与热点抢
  wlan0 的干扰源，多 IP 残留自动清退。
- **配网屏排版重做**：标题 / 热点名 / 密码用 52px 凸显字号，步骤与指引
  用 30px 标准字号，五步引导自上而下正序、行距收紧；移除无实际作用的
  二维码（MIUI 检测到热点无外网会自动回切，扫码路径全失效）。
- **状态图标断链红叉**：屏幕右上角 Wi-Fi / PC 连通图标，断链时灰底叠
  大红叉，弱视用户也能一眼分辨。
- **文字提亮**：时钟 / 日期五个主题色与"暂无任务"灰字整体提亮约 15%。

## 新增 / 改进（PC 端）

- **配对弹窗重做**：菜单「设备 → 配对设备」直接弹出深色风格配对框——
  未配对时为验证码式 6 格输码（自动跳格 / 退格回退 / Enter 确认 / 粘贴
  取数字，弹出即获键盘焦点）；已配对时显示设备列表，支持「解除配对」
  与「清除 Wi-Fi」（下发重新配网指令，设备清凭据重进配网模式、配对
  关系保留）。旧方案在菜单里轮询物理键，桌宠窗口不抢焦点导致漏键，
  已整体移除。
- **动作设定增强**：Live2D 动作设定页支持设备同步状态动作、1.x 角色
  缩略图、欢迎动作与角色配色（承接 v2.0.9 后的持续迭代）。

## 工程化

- **Windows 宿主交叉编译部署链**：新增 `deploy-cross.ps1`——本地
  aarch64 交叉编译（Arm GNU 13.2 + 设备 sysroot，cpr/curl/zlib 全静态
  单文件）直推设备，改码到设备运行约 1 分钟；禁止设备端本地编译。
- **仓库瘦身**：.gitignore 收紧（构建产物 / sysroot / 工具链 / 本地
  调试脚本全部忽略，提交视图从 9000+ 文件降至 37），清理历史遗留测试
  脚本与临时文件。
- **README 重写**：以 2.0 双形态（桌面 + 设备）为主线，重点介绍设备端
  形态与交叉编译构建；主仓库迁移至 Gitee `megrezsoft/duty-on`。

## 升级说明

- PC 端：直接覆盖安装即可，配置、形象与已配对设备保留。
- 设备端：通过「同步程序到设备」或 `deploy-cross.ps1` 重新部署；已配对
  设备无需重新配对。
- 首次配网建议操作顺序：手机连热点 `DutyOn-D8FB` → 停留在 WLAN 设置页
  等待自动弹出配网页（未弹出点"登录到网络"）→ 选 Wi-Fi 输密码 → 设备
  联网显示配对码 → PC 右键宠物「设备 → 配对设备」输码完成。
