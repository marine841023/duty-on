# DutyOn v2.0.9 — Wi-Fi 配对联网 + 电子相框照片播放 + Qoder Hook 全事件

## 新增（设备端）

- **Wi-Fi 局域网配对，告别 USB 直连**：设备接入家庭 Wi-Fi 后与 PC 同网段，
  通过 UDP 广播（`DUTYON_DISCOVER` / `DUTYON_OFFER`，端口 17522）自动发现
  PC，不再依赖 USB 线。首次配对时设备屏幕显示 6 位配对码，在 PC 菜单
  「设备 → 配对设备」输入即可完成信任绑定；配对令牌持久化到
  `~/.dutyon/config.json`，之后设备带 `X-DutyOn-Token` 头轮询 `/api/*`，
  令牌门控非法请求一律 401。
- **QR 配网**：设备处于 Wi-Fi AP 配网模式时，屏幕中央渲染二维码（自包含
  QR 编码器 + GL 纹理，`GL_NEAREST` 保证边缘锐利），手机扫码即可填入连接
  信息，配网更省事。
- **电子相框「指定文件夹」照片播放**：相框模式（deviceMode=frame）新增播放
  源 `frameSource`——动作轮播之外可选「指定文件夹」。PC 后端
  `GET /api/frame/photo` 每次随机回一张（蓄水池随机 + 目录列表 5s 缓存，大图
  在 PC 侧缩放到 max_side 并重编码 JPEG，按路径+mtime+size LRU 缓存），
  设备端后台线程取流进单槽 mailbox、渲染线程解码上传、cover 满屏绘制，每
  5 秒切一张并预取下一张，未就绪则保持当前不留白。照片始终留在 PC 磁盘、
  绝不批量同步；设备侧任意时刻最多一张已解码 RGBA + 一张在途字节，零落盘。
  PC 离线时兜底回动作轮播。
- **提示音改语音播报 + 声卡常开消爆音**：状态提示音换为语音；声卡常开架构
  消除短音效首尾的 DAC 上下电爆音。
- **屏幕亮度调节 + 设备子页整合**：设备菜单整合子页，新增屏幕亮度调节。
- **直出渲染自适应显示器模式**：废除旋转离屏合成，恢复直出渲染并自适应实际
  显示器模式；HDMI 真 48k 音频。

## 新增 / 改进（PC 端）

- **Qoder Hook 支持扩到 12 个事件**：经二进制对撞实测确认 Qoder IDE 与
  Qoder CN IDE（同为 1.32.0、同一 agent 二进制）实际派发的 hook 事件完全
  一致、共 12 种，本版全部接上——在原 6 种基础上新增 `PostToolUseFailure`
  （工具失败）、`SessionStart` / `SessionEnd`（会话起止）、`SubagentStart` /
  `SubagentStop`（子代理起止）、`PreCompact`（上下文压缩），让状态机靠真实
  信号推进、少依赖超时猜测。
- **IDE Hook 启动自动刷新**：事件表编译进程序，程序更新带来新事件时，启动即
  自动把各 IDE 的 `settings.json` / `hooks.json` 刷到最新（内容无变化则不写
  盘，幂等无副作用），用户无需再手动点「安装 IDE 集成」；hook 被删或后装
  IDE 也能自愈。
- **设备配对管理**：菜单「设备 → 配对设备」查看待配对 / 已配对设备、输入
  配对码确认、解除配对。
- **相框播放源菜单**：设备处于相框模式时，PC 菜单多出「相框播放」子菜单
  （动作轮播 / 指定文件夹 / 选择文件夹…），文件夹选择器用 `SHBrowseForFolderW`。

## 升级说明

- PC 端：直接覆盖安装即可，配置、形象与已配对设备保留。安装后首次启动会自动
  刷新 IDE hook（Qoder 用户建议重启 IDE 以重载 hook 配置）。
- 设备端：更新后需通过「同步程序到设备」重新部署；从 USB 直连升级到 Wi-Fi
  配对，需按屏幕二维码 / 提示重新配网并配对一次。
