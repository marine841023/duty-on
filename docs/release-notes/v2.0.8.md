# DutyOn v2.0.8 — 自定义角色 + 设备端动态布局

## 新增（PC 端）

- **自定义角色**：右键菜单「切换形象」里可新建自定义角色，为
  sleeping / working / alert 三个状态分别上传动画文件，支持
  **GIF / PNG / JPG**（静态图单帧长驻显示）；可随时更换或删除角色，
  删除时自动清理已上传的文件。文件经模态选择器复制到
  `~/.dutyon/animations/`，按时间戳命名不互相覆盖。
- `/api/animations/<file>` 按扩展名返回正确的 MIME 类型
  （image/gif、image/png、image/jpeg），设备端可正确识别并渲染
  自定义角色的静态图与动态图。

## 修复（PC 端）

- **右键菜单高度错误**：菜单窗口此前固定撑满整窗高度——内容少时
  底部空一块、内容稍多就出滚动条。现按内容自适应高度，超上限才滚动；
  点击菜单外区域关闭的判定同步修正（按实际菜单高度而非整窗）。
- 「语言」菜单项从设备分组移回主功能组（开机自启动之后）。

## 新增 / 改进（设备端）

- **未插 USB 开机即电子相框**：设备端初始模式由 multi 改为 frame，
  没连电脑时直接全屏轮播角色动作（大时钟 + 日期），插入 USB 后
  PC 下发的模式正常覆盖，断连保持最近值。
- **USB 连接状态小插头**：屏幕右上角常驻图标——已连接为绿色插头
  插合，未连接为红色插头与线缆断开留缝，纯色几何绘制无贴图依赖。
- **多任务模式动态分屏**：任务面板高度按任务数实时伸缩
  （行数×行高 + 顶隙），角色占据「时钟下沿 ~ 面板顶」之间的全部
  区域并**垂直居中**——任务少时角色大且居中、不再半屏空黑或贴底
  下沉，任务多时面板自动变高。多任务模式时钟顶部留白加大，
  避免压住角色头顶。

## 升级说明

- PC 端：直接覆盖安装即可，配置与形象保留。
- 设备端：更新后需通过「同步程序到设备」重新部署。
