# DutyOn v2.0.5 — 修复安装版 Live2D 不显示

## 修复

- **安装版 Live2D 精灵渲染空白**：Cubism SDK 5 运行时需要从
  `<安装目录>\FrameworkShaders\` 加载 OpenGL 着色器，而 NSIS 安装包的
  打包清单此前遗漏了该目录——开发环境直跑 `build\Release`（shader 就在
  旁边）从未暴露，只有安装版中招：Live2D 模型零像素渲染（ImGui 面板与
  GIF 形象不受影响，因此任务列表一切正常）。
  现已将 `FrameworkShaders` 全部 10 个着色器文件打包进安装器，
  卸载时一并清理。
- **影响范围**：v2.0.0 ~ v2.0.4 的所有已发布安装包均受影响，
  重新安装 v2.0.5 即可恢复。

## 排查记录（供参考）

定位链：进程存活 → API 正常 → 窗口可见 → 像素采样发现精灵区全透明而
任务列表正常 → 模型文件齐全 → `build\Release` 有 `FrameworkShaders`
而安装目录没有 → 实锤打包遗漏。拷贝后像素采样确认模型渲染恢复，
重打包体积涨幅（8.4MB → 8.66MB）与 10 个小文本 shader 吻合。

## 升级说明

- 直接覆盖安装即可，配置与形象保留；GIF 用户无感知，
  Live2D 用户升级后模型恢复正常显示。
