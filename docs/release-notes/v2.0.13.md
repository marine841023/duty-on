# DutyOn v2.0.13 — Codex Hook 检测与托盘菜单

## 变更

- Codex/OpenCode 进程名精确匹配；进程存在不再刷新所有会话活动时间，枚举失败不误删会话。
- Codex 增加中断、结束、模型、子代理、压缩事件；处理旧回合迟到事件、并行工具与待确认状态。
- Hook 安装支持 `CODEX_HOME` 和中文路径，保留共享 matcher 内其他程序的 handler，备份失败时保留原配置。
- PowerShell 桥接使用 UTF-8，优先使用事件内项目路径；丢弃缺少会话标识的事件，日志不再记录完整输入。
- Windows 托盘右键增加显示/隐藏、移至屏幕正中、退出；居中会恢复显示并退出贴边模式。
- 安装器与升级包补齐 Hook 脚本，修复安装后无法自动配置 Hook 的问题；安装器版本由 CMake 传入。
- 更新中英主页、贡献说明与问题/PR 模板，补充测试入口和安装包目录。

## 验证与边界

- Windows Release 构建、独立后端 CTest、13 个 PowerShell 桥接场景通过，Shell 桥接语法通过。
- 完整程序启动、渲染与正常退出已验证；托盘菜单点击效果尚未完成实测。
- 构建仍有既有 `LNK4098` 警告；本次未重新验证 ARM 真机或 macOS/Linux Hook 端到端流程。
- Codex CLI 升级 Hook 后需在 `/hooks` 中检查并信任定义；本机 Hook 不保证观测云端会话。
  详细分析与限制见 [Hook Review](../hook-review.md)。
