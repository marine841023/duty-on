# DutyOn v2.0.1 — Thinking 超时修复版

v2.0 首个维护版本。核心架构不变：**单个原生 C++ 进程**（无 WebView、无浏览器
运行时），`dutyon-pet.exe` 内嵌 HTTP 服务器 + 状态机 + IDE 扫描 + 系统监控，
GLFW + OpenGL + Cubism SDK 原生渲染 Live2D/GIF 精灵，实测内存 ~116MB。

## 修复

- **LLM 长生成不再误判空闲（故障 4）**：模型生成长回复期间（思考状态）完全
  静默——不产生任何 hook 事件，静默时长就等于回复生成耗时。实测抓包：
  PostToolUse 之后模型连续生成 3 分 52 秒才发出下一个工具调用，原有的 3 分钟
  工作超时先到，把仍在生成的会话误判为空闲、宠物开始睡觉。
  本版为思考状态单独设置 10 分钟超时兜底（`kThinkingTimeout`），长分析、
  长代码生成期间宠物保持"思考中"。
- 同源修复已同步到 1.x 线（[v1.3.3](https://github.com/marine841023/duty-on/releases/tag/v1.3.3)），
  两条产品线状态机行为一致。

## 升级说明

- 直接运行安装包覆盖安装即可；安装器会自动定位原有安装目录（含 1.x 的），
  配置、GIF 形象与 Live2D 模型共用保留。
- 完整故障记录见仓库 `docs/fault-records.md`（故障 1-4）。
