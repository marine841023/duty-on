# DutyOn v2.0.15 — 云服务与异步提问提醒

## 变更

- 新增 Linux + Docker 云服务部署方案及手机可用的云空间网页，提供安装器、分发 ZIP、OTA 下载、注册登录、私有动画/音频/Live2D 上传管理。
- 发布包采用 SHA-256 固定下载，上传支持配额、路径检查和并发覆盖保护；密码加盐哈希，注销持久化，配置仅同步白名单。
- Windows 云客户端使用 WinHTTP 支持 HTTPS 系统证书验证，校验恢复文件和更新包；保留云端独有内容，同名云文件变化时提示先恢复。支持中文内容文件名。
- Codex `request_user_input_async`（含命名空间）触发 Attention；工具返回及 Stop 保留异步提问，回答、取消或失败后清理。已停止代理的迟到工具事件不会重新激活任务。

## 验证与部署边界

服务端单元测试、Go vet、Linux amd64 交叉编译及 Windows Release 构建通过；后端回归覆盖异步提问的保留、清理和乱序事件。

真实 C++ 云客户端端到端验证通过：注册登录、中文文件上传、配置过滤、云端冲突保护、恢复、再次同步、更新检查及注销失效。三类实际安装包已在隔离测试服务发布，HTTP 下载的长度和 SHA-256 均一致；云空间网页已检查桌面及 390px 手机布局。

本机桌宠已替换为新版并运行验证：异步提问增加 Attention 事件，PostToolUse、并行工具及 Stop 保留提醒，回答/失败后清理，迟到工具不重新激活任务；子代理确认及重复事件去重回归通过。测试会话均已清理。

服务端采用单实例 JSON/文件存储。ECS 和正式域名待准备，当前分发包没有预置线上 OTA 主地址。部署步骤及 API 见 [云服务文档](../../server/README.md)；Docker 仍需在 Linux 主机验收。图片生成角色、声音克隆尚未接入。

安装包输出目录为 `tools/dist/`：`DutyOn_2.0.15_x64-setup.exe`、`DutyOn-v2.0.15.zip`、`DutyOn-update-v2.0.15.zip`。本文不表示已发布线上 Release。
