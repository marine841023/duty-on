# DutyOn v2.0.12 — Trae 新版兼容修复

## 修复

- **Trae 升级后项目从任务列表消失**：Trae 新版把窗口标题品牌名改为全大写
  （`xxx - 项目名 - TRAE CN`），而 IDE 扫描的标题后缀匹配是大小写敏感的
  （`" - Trae CN"`），匹配失败导致宠物任务列表看不到 Trae 的项目。窗口
  标题后缀判定、提权后缀剥离与无项目黑名单全部改为大小写不敏感，品牌名
  日后再变体也不会失效（进程名匹配本就不区分大小写，未受影响）。

## 工程化

- 补齐 v2.0.11 遗漏入库的 `third_party/deps/sha256/sha256.h`（云同步
  `cloud_client.cpp` 依赖；当时被 gitignore 拦下，克隆后无法编译），经
  NIST 标准向量与系统哈希交叉验证；修复 `build-package.ps1` 双 BOM。

## 升级说明

- PC 端直接覆盖安装，配置、形象与已配对设备保留。
