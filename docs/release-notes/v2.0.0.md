# DutyOn v2.0.0 — 原生 C++ 重写版

> 下载：[GitHub](https://github.com/marine841023/duty-on/releases/download/v2.0.0/DutyOn-v2.0.0.zip) · [Gitee](https://gitee.com/megrezsoft/dutyo/releases/download/v2.0.0/DutyOn-v2.0.0.zip)（.zip，解压后运行安装器）

## 🚀 整个应用重写为单个原生 C++ 进程

无 WebView、无浏览器运行时、无 Rust 后端。一个 `dutyon-pet.exe` 内嵌 HTTP 服务器、状态机、IDE 扫描器和系统指标采样，用 GLFW + OpenGL + Live2D Cubism Native SDK（或 GIF 精灵）原生渲染。这也是未来移植到低成本 ARM 硬件设备的代码基线。

## 💡 内存亮点：实测数字，所见即所得

同一台机器、同样挂着 Live2D 精灵的实测结果：

| 版本 | 进程构成 | 工作集合计 | 私有内存合计 |
|------|----------|-----------|-------------|
| 1.x（WebView 架构） | duty-on.exe（~70MB）+ 6 个 WebView2 浏览器进程（~396MB） | ~465MB | ~195MB |
| **2.0（原生 C++）** | **dutyon-pet.exe 单进程，无任何隐藏进程** | **~116MB** | **~114MB** |

### 📌 关于 1.x 旧宣传数字的勘误

1.x 时代的文案曾宣传"内存仅 ~80MB"。**这个数字写得不准确**：它只统计了主进程，没有算上 WebView2 运行时拉起的整组浏览器进程（实测约 400MB），实际总占用是宣传数字的数倍。这是我们当时的疏忽，特此说明。

2.0 彻底移除 WebView2——任务管理器里只有一个进程，占用所见即所得，**实际总占用真实下降一半以上**。

## ✨ 功能

- **GIF 自定义角色**：任意 GIF / PNG / JPG / WebP / MP4 / WebM，睡觉 / 忙碌 / 提醒三状态分别设置
- **Live2D 原生渲染**：Cubism Native SDK + OpenGL，21 个内置动作，支持自定义 Cubism 4 模型
- **五大 IDE 监控**：Trae / Qoder / Cursor / Codex / OpenCode，Hook 事件实时驱动
- **系统监控面板**：CPU / 内存 / GPU / 网络实时曲线 + 进程自身占用
- **与 1.x 交替安装**：安装器自动定位原有目录，共用 `~/.dutyon` 配置 / GIF / 模型，可随时互装互回
- **8 种语言**、迷你模式、开机自启、位置记忆

## 🔄 与 1.x 的关系

- 1.x（WebView 版，支持 macOS/Linux）继续在 `master` 分支维护，最新 v1.3.2
- 2.0 与 1.x 可互相覆盖安装、共用配置，随时切换
- 从 1.x 升级：直接运行 2.0 安装器即可，无需卸载

## 📦 安装

解压 zip，运行 `DutyOn_2.0.0_x64-setup.exe`（当前用户安装，含简/繁中/英/日/韩语言选择，支持开机自启选项）。Windows 10/11 x64。
