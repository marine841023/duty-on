# DutyOn v2.0.4 — 关闭项目秒级移除

## 修复

- **关闭的项目不再滞留任务列表**：此前窗口扫描的删除被"同 IDE 类型的其他
  窗口仍在"条件抑制——只要还开着另一个 Trae/Qoder/Cursor 窗口，关掉的
  项目就会一直挂在列表里，最长要到 10 分钟会话超时才消失（用户实测反馈）。
  现在窗口消失即视为**确定性信号**（EnumWindows 可靠）：仅保留 3 次扫描
  （约 12 秒）防闪烁宽限，之后立即从列表移除。

## 分档逻辑（本版明确）

| 场景 | 处理 |
|------|------|
| 窗口扫描确认消失 | ~12 秒内移除（防重载闪烁宽限） |
| 思考中静默（LLM 生成期无 hook 事件） | 10 分钟超时档 |
| 工具执行中静默 | 15 分钟超时档 |
| Codex/OpenCode CLI 会话（无窗口可扫） | 会话超时档 |

## 说明

- 代价说明：IDE 打开设置页等标题暂时不可解析的场景，会话会在 12 秒后被移除，
  回到项目页时自动重建（窗口扫描占位 + hook 恢复），自愈无感。
- 升级直接覆盖安装，配置与形象保留。
