# DutyOn v1.3.3 — Hook 状态机修复版

## 修复

- **LLM 长生成不再误判空闲（故障 4）**：模型生成长回复期间（思考状态）完全静默——
  不产生任何 hook 事件，静默时长就等于回复生成耗时。实测抓包：PostToolUse 之后
  模型连续生成 3 分 52 秒才发出下一个工具调用，原有的 3 分钟工作超时先到，
  把仍在生成的会话误判为空闲、宠物开始睡觉。
  本版为思考状态单独设置 10 分钟超时兜底，长分析、长代码生成期间宠物保持"思考中"。

与 v2.0.1（原生 C++ 版）包含同源修复，两个版本行为一致。

## 升级说明

- 直接运行安装包覆盖安装即可，配置与 Live2D/GIF 形象保留。
- 从 2.0 版本覆盖安装同样支持（共用 `~/.dutyon` 配置）。
