# DutyOn v2.0.14 — 子代理与确认提醒

## 变更

- 按会话、代理、工具调用和确认请求独立记账。主代理 Stop 保留仍在工作的子代理；主会话 Interrupt 取消整树，SessionEnd 删除整会话。
- 权限请求可早于工具开始；重复请求、已结束调用的迟到通知不重复提醒。普通通知和兄弟代理的完成事件不会清除其他确认。
- 新增 `alertSeq`，使待确认期间的新请求与每 60 秒提醒可传到设备；设备端遵守提醒静音设置。
- OpenCode 插件按 callID 去重工具流，接入权限及问题的 asked/replied/rejected（含 question.v2），合并父子会话，保留已答复请求记录。
- Cursor 接入会话结束、工具失败、子代理与压缩事件；需要响应的观察 Hook 返回合法 JSON，避免桥接异常干扰 IDE。
- 修复确认关键词数组数量错误引发的越界读取；数组数量统一自动计算。

## 支持范围与验证

后端回归、19 个 Windows PowerShell 桥接场景、OpenCode 事件流回归及 Shell 语法检查覆盖并发、乱序、取消、去重和安装保留。构建及运行验证结果见 [Hook Review](../hook-review.md)。

Windows 与 ARM 构建通过，本机程序和设备均已更新运行。真实接口回归通过，设备日志确认连续两个确认请求分别触发了提醒音播放调用；未将日志验证描述为人工听音验证。

Cursor 官方 Hook 不提供通用的权限等待/答复事件，且 subagentStop 缺少稳定身份，因此其子代理生命周期只作为会话活动信号，不声称捕获全部确认卡片。无调用/代理身份的旧 IDE 事件仍存在关联精度限制。异步提问工具返回不代表用户已答，不能套用同步 Pre/Post 清理规则。Codex 的 Hook 信任仍由用户在 IDE 内管理。
