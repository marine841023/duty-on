# DutyOn v2.0.7 — 项目检测稳定化 + 状态动作即时切换

## 修复（PC 端）

- **空闲时项目列表间歇性整体消失**：Qoder CN 单个进程同时开多个 IDE 窗口时，
  进程一忙（AI 流式生成 / 索引 / 渲染），窗口扫描用 `SendMessageTimeout(WM_GETTEXT)`
  读标题会对该进程名下所有窗口集体超时（或被 `SMTO_ABORTIFHUNG` 中止），一轮
  扫描漏掉全部窗口；而纯窗口占位会话是“一次没扫到就立即删除”，于是宠物项目
  列表瞬间清空、几秒后又恢复（表现为“空闲时项目时有时无”）。现改为优先用
  `GetWindowText` —— 对跨进程窗口直接返回 OS 缓存标题、不向目标进程投递任何
  消息，目标再忙甚至被判“未响应”都读得到；仅当缓存标题为空时才回退到 250ms
  硬超时的消息读，保留兜底。
- **切换状态时要等旧动作播完**：进入“思考中”等新状态时，若上一个待机动作
  （如打哈欠）尚未播完，新动作不会立即起播，观感延迟。现循环动作发生变化时
  用 Force 优先级立即打断旧动作、马上淡入新动作，状态切换即时响应。

## 新增 / 改进（设备端）

- **事件提示音**：任务开始 / 任务结束 / 待确认提醒三种提示音，PCM 由正弦波
  合成（无需音频资源文件），经 `aplay` 输出到 ALSA；提醒播 3 次、开始/结束
  各 1 次；后台线程播放不阻塞渲染循环，无可用声卡时静默。可用环境变量
  `DUTYON_AUDIODEV` 指定 I2S/USB 声卡（如 `hw:1,0`）。
- **任务列表 UI 重构**：由铺满下半屏改为贴角色区下方堆叠的紧凑半透明黑圆角
  卡片（与角色留一线距离），行块圆角内缩、左边框改圆角竖条，日期行移至屏幕
  下缘；任务少时是一张小卡片，不再是整屏底栏。
- **补齐设备资源**：中文字体 `font-noto-sc.otf`、USB 连接提示图 `prompt-usb.png`
  随库入库（此前遗漏，设备端文字渲染 / 提示横幅依赖）。

## 升级说明

- PC 端：直接覆盖安装即可，配置与形象保留。
- 设备端：更新后需重新部署；提示音依赖 ALSA / `aplay`。
